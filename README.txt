CONTACTO / FORMSPREE
GitHub Pages no ejecuta PHP, Ruby ni Python del lado del servidor. Para activar el formulario debes crear un formulario en Formspree y reemplazar en contacto.html:
https://formspree.io/f/REEMPLAZAR_ID

Por tu endpoint real, por ejemplo:
https://formspree.io/f/abc123xy

No inventes el endpoint. Créalo en tu cuenta de Formspree.

La versión actual mantiene el sitio estático y no requiere base de datos.
